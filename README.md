# Naomiles — Personal Portfolio

Personal portfolio website based on [vCard](https://github.com/codewithsadee/vcard-personal-portfolio) template.

## Sections

- **About** — intro and what I'm doing (backend, web, devops, data science)
- **Resume** — education, experience, skills with progress bars
- **Portfolio** — project showcase with filter tabs
- **Blog** — placeholder for future posts
- **Contact** — contact form (frontend only)

## Deployment

This is a static HTML/CSS/JS site served directly by GitHub Pages.
No build step needed — just push to `master` and GitHub Pages serves the files.

The `.nojekyll` file tells GitHub to skip Jekyll processing.

Visit: https://naomiles.github.io/-http-github.io/

## Customization

- Edit `index.html` to change content
- Replace images in `assets/images/`
- Adjust colors in `assets/css/style.css`
