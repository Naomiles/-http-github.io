## A quick taste of Chirpy

Chirpy supports prompt boxes:

> This is a tip box — pretty handy for highlighting useful information.
{: .prompt-tip }

> This is a warning box — use it to draw attention to pitfalls.
{: .prompt-warning }

And code blocks with syntax highlighting:

```python
def greet(name: str) -> str:
    """Say hello to the visitor."""
    return f"Hello, {name}! Welcome to my site."

print(greet("you"))
```
